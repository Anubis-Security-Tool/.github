# 🛡️ Anubis Security Tool

### Open-Source Security. Intelligent Automation. Total Control.

**Welcome to Anubis Security Tool** — an open-source ecosystem built for cybersecurity research, vulnerability analysis, system administration, and intelligent security automation.

We develop cross-platform tools that bring together secure remote access, vulnerability intelligence, binary analysis, network infrastructure, and AI-assisted security workflows.

Our mission is to make powerful security tools accessible, modular, and practical for developers, security researchers, system administrators, and DevSecOps teams.

## ⚡ The Anubis Ecosystem

Anubis is designed as a modular ecosystem rather than a collection of isolated utilities. Each component focuses on a specific security or infrastructure task, with a shared vision of extensibility, automation, and cross-platform support.

| Module | Focus | Description |
|:--|:--|:--|
| 🛡️ **[Anubis Core](https://github.com/Anubis-Security-Tool/anubis)** | Terminal & Remote Access | Cross-platform desktop application for terminal workflows, SSH/SFTP, remote sessions, file transfers, and system administration. |
| 🔍 **[Anubis Aegis](https://github.com/Anubis-Security-Tool/Anubis-Aegis-CVE-Scanner)** | CVE Scanner · Vulnerability Intelligence | Identify known vulnerabilities, inspect software components, and correlate software versions with vulnerability intelligence. |
| 🪲 **Anubis Scarab** | DLL Scanner · Binary Analysis | Analyze DLLs, imports, dependencies, and potentially vulnerable or suspicious binary components. |
| 🌐 **Anubis Atlas** | Proxy Server · Network Gateway | Proxy infrastructure based on GoProxy, designed for connection routing and network operations. |
| 🧠 **Anubis Oracle** | AI Pentest Agent · Security Automation | AI-assisted, authorized penetration testing, security assessment analysis, and report preparation. |
| ⚙️ **Anubis Osiris** | Cross-Platform Automation · OS Control | Automate workflows across Windows, Linux, and macOS through scripts, task orchestration, and system operations. |

*Module names describe the ecosystem roadmap and intended responsibilities. Refer to each repository for its current implementation and availability.*

## 🚀 Explore Our Projects

### 💻 Core Application

**[Anubis Security Tool](https://github.com/Anubis-Security-Tool/anubis)**

Your cross-platform workspace for terminal access, remote connections, file transfers, and administration workflows.

- 🖥️ Windows, Linux, and macOS
- 🔐 SSH, SFTP/FTP, RDP, VNC, and other remote-access protocols
- 🧰 Connection profiles, quick commands, and workflow utilities
- 🌐 Separate web distribution and managed-device access components

### 🌐 Web & Infrastructure

- **[Anubis Web](https://github.com/Anubis-Security-Tool/anubis-web)** — browser-based workspace for remote-access workflows.
- **[Anubis Managed Access](https://github.com/Anubis-Security-Tool/anubis-managed-access)** — device enrollment and controlled remote access.
- **[Anubis Resources](https://github.com/Anubis-Security-Tool/anubis-resource)** — branding, application icons, and cross-platform build resources.
- **[Node Sync](https://github.com/Anubis-Security-Tool/anubis-sync-server-node)** — dependency-free, self-hosted synchronization backend.
- **[Cloudflare Sync](https://github.com/Anubis-Security-Tool/anubis-sync-server-cloudflare)** — alternative Workers/D1 synchronization backend.
- **[Package Sources](https://github.com/Anubis-Security-Tool/anubis-packages)** — the owned scoped SSH, sync, terminal, locale, theme and transfer-package sources.
- **[Download Site](https://github.com/Anubis-Security-Tool/anubis-site)** — independent release metadata, download-site generation and Web source installer wrappers.

The optional [HTTP tunnel](https://github.com/Anubis-Security-Tool/anubis-http-tunnel)
and [legacy RDP.js](https://github.com/Anubis-Security-Tool/anubis-rdpjs) components
retain their GPL licenses and are separate from the current MIT application.
The RDP.js reference is not its active RDP backend.

For a complete local Desktop + Web + Sync source setup, use the
[source-suite guide](https://github.com/Anubis-Security-Tool/anubis/blob/main/docs/SOURCE-INSTALL.md).
For another computer, use the
[migration guide](https://github.com/Anubis-Security-Tool/anubis/blob/main/docs/MIGRATION.md);
do not transfer machine-bound encryption or managed-device identities blindly.
